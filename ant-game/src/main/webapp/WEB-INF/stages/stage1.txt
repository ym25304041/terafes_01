; ============================================================
; ステージ定義ファイル（ファイル名は stage<番号>.txt）
;
; 書き方:
;   ・「;」で始まる行はコメント、空行は無視されます。
;   ・name: の右側にステージ名を書きます。
;   ・description: の右側に、ステージ選択画面に表示する一言説明を書きます（省略できます）。
;   ・facing: の右側に、アリの最初の向き（right / left / up / down）を書きます。省略すると right（右向き）。
;     「前へ移動」「前へジャンプ」は、アリが向いている方向へ進みます。
;   ・map: の次の行から、5行×9文字でマップを書きます。
;
; マップの記号:
;   .  道      #  壁      P  落とし穴      G  ゴール
;   S  スタート地点（1つだけ。地形は道）
;   M  物資（道の上に置かれる）      W  武器（道の上に置かれる）
;   X  敵（道の上にいる。'E' はドアに使うので、敵は 'X'）
;   a〜e  スイッチ（小文字）        A〜E  ドア（大文字）
;       同じ文字どうしが対応する。 a のスイッチを作動させると A のドアがすべて開く。
;       スイッチを置いたら、対応するドアも必ず置く（逆も同じ）。
;
; アイテムとスイッチの動き（すべて自動）:
;   ・アリがアイテムのマスに着くと自動で取得する（物資・武器を1つずつ持てる）。
;   ・物資を持ってスイッチのマスに着くと、物資を消費してドアが開く。
;   ・武器を持って敵のマスに着くと敵を討伐して進める（武器は減らない）。
;     武器を持たずに着くと敗北してゲームオーバー。
; ============================================================
